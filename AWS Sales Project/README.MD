# Adventure Works Sales & Returns Dashboard — Power BI

## Business objective
Analyze sales performance across time, geography, products and customers, while reviewing return activity to support commercial and operational decisions.

## Dashboard-reported metrics
- **25K+ orders**
- **18K customers**
- **293 products**
- **$24.9M revenue view**
- **1,828 returned units**
- **2.17% return rate**

## Quantitative findings
The dashboard reports 1,828 returned units and a 2.17% return rate. That rate should be interpreted using the report's exact denominator (for example, orders or units) before comparing it with another business or period. The $24.9M revenue view and 25K+ orders establish overall scale, but do not identify which product or territory drives the result.

## Analysis questions
- How does revenue move across the 2015–2017 period?
- Which products, categories, customers and territories contribute most to revenue?
- Which products or categories have higher return activity?
- How do orders and customer patterns change over time?
- Where do sales contribution and return behavior diverge?

## Business recommendations
1. Compare product/category revenue contribution with return quantity and return rate; investigate high-sales/high-return items first.
2. Review territory contribution to focus commercial follow-up.
3. Use customer rankings to support targeted account review, without assuming high spend implies loyalty.
4. Validate the return-rate denominator and reporting filters before presenting it as an operational benchmark.
