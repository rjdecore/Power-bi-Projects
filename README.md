# Power BI Business Analytics Portfolio

## Repository Objective
A collection of interactive Power BI dashboards built around sales, customer, operations, healthcare, HR, retail, travel, sports, and service-analysis use cases.

## Core Workflow
**Data preparation → data modeling → DAX measures → interactive reporting → business insights**

## Skills Demonstrated
- Power Query
- Data modeling and relationships
- DAX measures and KPIs
- Time-intelligence analysis
- Drill-through
- Bookmarks
- Dynamic measures/titles
- Custom tooltips
- Conditional formatting
- Geospatial analysis
- Forecasting

Each project folder contains the available PBIX/report files, source data, dashboard exports, visuals, and project-specific README.

## Primary Tooling
**Power BI Desktop | Power Query | DAX | Data Modeling | Business Intelligence**
