# Pizza Sales Analytics — SQL + Power BI

## Business Objective
Combine SQL-based KPI analysis with Power BI dashboarding to understand pizza revenue, order volume, product demand, category mix, size preference, and time-based ordering patterns.

## Dataset
One year of pizza sales data covering **January–December 2015**.

## Reported KPIs
- **₹817,860 revenue**
- **21,350 orders**
- **49,574 pizzas sold**
- **₹38.31 average order value**
- **2.32 pizzas per order**

## Business Questions
- Which days and months generate the most orders?
- Which categories contribute most revenue?
- Which sizes are most popular?
- Which pizzas are the best and worst sellers?
- How do revenue and quantity vary by product?

## Workflow
**SQL exploration → KPI calculation → business analysis → Power BI visualization**

## Tech Stack
**MySQL | SQL | Power BI | DAX | Sales Analytics | Data Visualization**
