# Uber Trip Detail & Operations Dashboard — Power BI

## Business Objective
Analyze Uber trips to understand booking volume, revenue, trip distance/time, payment behavior, vehicle performance, and location-based demand.

## Dashboard Areas

### Executive Overview
Tracks:
- Total bookings
- Booking value/revenue
- Average booking value
- Total and average trip distance
- Average trip time
- Payment type
- Day/night demand
- Vehicle performance

### Time Analysis
- 10-minute pickup intervals
- Weekday vs weekend trends
- Hour-by-day heatmap
- Peak and off-peak demand

### Trip Details
A drill-through page provides detailed trip-level records with pickup, drop-off, distance, revenue, and vehicle information.

## Advanced Power BI Features
- Dynamic measure selector using disconnected tables
- Dynamic titles
- Drill-through
- Bookmarks
- Custom tooltips
- Conditional formatting
- Interactive slicers
- Export functionality

## Business Use
The dashboard supports driver allocation, demand planning, vehicle comparison, and identification of high-value or long-distance trips.

## Tech Stack
**Power BI | DAX | Data Modeling | Drill-through | Bookmarks | Dynamic Measures**

## Business Questions Addressed
- When and where does trip demand peak?
- How do booking value, distance and trip duration vary by time and vehicle?
- Which payment types and vehicle categories account for activity?

## Key Findings & Business Value
Use the overview and time-analysis pages to identify peak demand intervals, high-activity areas and differences across vehicle/payment segments. Quote exact totals from the report's KPI cards and state the filters used. These patterns can inform driver allocation, shift planning and vehicle mix.
